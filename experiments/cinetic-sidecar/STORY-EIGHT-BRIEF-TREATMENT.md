## Five gating checks
1. **Artifact:** MP4 and actual alpha MOV `ap4h` / `yuva444p`, 30 fps, exactly 240 frames, fully public synthetic. Render twice only if artifact integrity tests warrant it.
2. **Decoded QA:** Samples must span all three acts and boundaries; alpha corners/side margins truly transparent; source font sha/cmap evidence, no source text leakage or missing glyphs.
3. **Independent Visual Design Review:** Inspect actual rendered full-speed video and timecoded frames, practical readability (especially at native mobile scale), whether the node motion truly proves the narrative, animation rhythm and spatial collision. A rubric score is never a release gate by itself; don't score unseen evidence.

5. **Rights & editability:** Commercial HyperFrames/GSAP exact use classification, native Windows Premiere, font approval and meaningful contrast/flash QA require separate evidence. Preserve C2 synthetic results and production main unchanged.
