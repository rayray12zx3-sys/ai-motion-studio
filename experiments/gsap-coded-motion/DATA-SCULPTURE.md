# Original volumetric data sculpture — specialized animation R&D
The previous two-shot demo only changed the palette on one orbit composition. This adds a materially different **actual Three.js scene** for the second shot: four frame-deformed double-sided ribbon meshes (226 vertices each), 28 independently transformed GPU instances, six spatial orbit frames, PBR material, three-point lighting and an original procedural depth shader. All motion is derived from a requested frame index and has no wall-clock, model inference, third-party media or external fetch. The *original orbit scene* remains the first shot, the *sculpture scene* is the second. They share GSAP typography, deterministic camera paths, protected-title audit and GPU shader compositor.
**Not a claim of visual-professional quality**: the goal is true engine/geometry diversity and reusable native GPU motion, not retouching the old V4. This remains stacked R&D and does not change the authoritative Canvas/FFmpeg/Konva production path. Check full CI (especially 300 decoded video frames) before claiming technical approval.
