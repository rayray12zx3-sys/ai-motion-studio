# Per-shot, film-safe 3D composition
Previous film-wide scalar fit constrained two visually different rigs to the smallest common subject size (0.368 in a verified browser audit), leaving small floating objects amid excessive negative space. This original layout solver selects a distinct **one-time constant scale and Y placement per shot** from allowed candidates while checking each authored camera frame, preserving whole-film typography/footers, visible viewport and no per-frame pumping. Distinct per-shot setup does not mean arbitrary cutting; matched cross-shot semantic continuity is a separate future creative gate. This change wires the **real WebGL scene** to the new fitter. Exact-head GPU/encoded continuity and screen evidence still required. R&D only; no automatic official renderer adoption.
