# M11.1 Product UI choreography baseline

This four-second 120-frame 30fps synthetic motion baseline is an original continuous Product UI motion study. **It is not a native APP screen, production S03 shot replacement, or imported prompt-motion.com art.**

## Timed beats

- 0–18f: a single compositional UI board enters smoothly
- 12–45f: cursor approaches card A, clicks, selection morphs
- 48–71f: cursor traverses to B, clicks; both cards become connected
- 68–94f: two card geometries translate into one rounded success capsule; no cut or scene replacement
- 82–108f: that same capsule becomes an editorial Combo 02 display, progress bar resolves
- 108–119f: stable result hold

Small damped spring overshoot is limited to 2.2%. Palette is dark charcoal, neutral offwhite and one mint accent with restrained amber highlight; no flashy particles or arbitrary wipes.

Only synthetic public text appears. Render via drawProductUIChoreographyFrame(profile,frame), validated 9:16 safe region, with a custom alpha-based mask review separately at the actual private production location. Reels/FB UI still requires operator-specific static mask and on-device human QC. Do not claim the public stock-safe rectangle alone proves platform safety.

Acceptance: 120 exactly deterministic frame samples, no alpha outside safe region, continuous tracked card geometry at stage boundaries, changed visible states, true rendered 30fps review MP4, and user art direction approval after reviewing video.
